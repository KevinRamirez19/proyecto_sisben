Paso 1 · Metodología

Flujo en Orange Data Mining

Pipeline completo desde la carga del dataset hasta la evaluación del modelo de clustering.

Fuente 1 · sisben_orange.csv

Dataset principal con 315.612 filas y 38 variables (1 meta). Contiene todos los registros individuales del SISBEN IV en Cundinamarca con indicadores de carencia, clasificación de pobreza e IPM score.

Fuente 2 · sisben_municipios.csv

Dataset agregado municipal con 928 filas y 22 variables (1 meta). Contiene los promedios de nivel SISBEN e IPM por municipio, utilizado para el análisis territorial y el scatter plot municipal.

Paso 1b · Preprocesamiento

Limpieza y normalización de datos

Configuración del widget Preprocess en Orange para estandarizar variables e imputar valores faltantes antes del clustering.

Evidencia Orange · Preprocess

Normalización e imputación aplicadas

El widget Preprocess de Orange se configuró con dos etapas encadenadas sobre los 315.612 registros. La primera etapa aplica Normalize Features con estandarización a μ=0, σ²=1 (Z-score), garantizando que ninguna variable con mayor rango domine la distancia euclidiana del K-Means.

La segunda etapa aplica Impute Missing Values con la estrategia Average / Most frequent, reemplazando valores nulos por la media (variables continuas) o la moda (variables categóricas). Esta combinación garantiza que el dataset esté libre de valores faltantes y que las variables binarias (I1–I15) sean comparables entre sí.

  • Normalización: Standardize μ=0, σ²=1 (Z-score)
  • Imputación: Average / Most frequent
  • Entrada: 316k registros · Salida: 316k registros limpios
  • Select Relevant Features activado para filtrar variables irrelevantes
Paso 1c · Pipeline completo

Flujo en Orange Data Mining

Pipeline completo desde la carga del dataset hasta la evaluación del modelo de clustering y clasificación.

Evidencia Orange · Flujo de trabajo

Pipeline completo del análisis

El flujo construido en Orange Data Mining integra la importación del CSV mediante CSV File Import, seguido de un nodo Select Columns que filtra los 15 indicadores binarios de carencia (I1–I15). El nodo central k-Means aplica el algoritmo con k=4 y normalización activada.

Los resultados se evalúan simultáneamente con Box Plot para analizar la distribución del IPM por cluster, Scatter Plot para visualizar la separación en el espacio PCA, y Data Table para explorar los registros asignados a cada grupo.

  • Entrada: 315.612 registros · 15 variables binarias
  • Preprocesamiento: normalización Z-score + imputación
  • Salida: etiqueta de cluster (C1–C4) por cada registro
Paso 2 · Configuración

Parámetros del nodo K-Means en Orange

Configuración utilizada en el widget de K-Means para garantizar la reproducibilidad y calidad de la segmentación.

Evidencia Orange · Widget K-Means

Configuración del modelo

El widget K-Means de Orange fue configurado con k=4 clusters fijos, seleccionado tras evaluar el método del codo entre k=2 y k=8. La inicialización utilizada fue KMeans++, que garantiza centroides iniciales bien distribuidos y reduce la probabilidad de convergencia a mínimos locales.

Se ejecutaron 10 re-inicializaciones con un máximo de 300 iteraciones por ejecución, conservando el resultado con menor inercia. La normalización de columnas fue activada para evitar que variables con mayor varianza dominen la métrica euclidiana.

  • Inicialización: KMeans++ · 10 re-runs
  • Iteraciones máximas: 300 por ejecución
  • Normalización: activada sobre las 15 variables
  • Métrica: distancia euclidiana
Paso 3 · Selección de k

Método del codo — PCA

Análisis de varianza explicada para determinar el número óptimo de componentes y validar la elección de k=4.

Evidencia Orange · PCA

Varianza explicada acumulada

El análisis PCA aplicado sobre los 15 indicadores binarios muestra que los primeros 8 componentes principales explican el 54,1% de la varianza total. La curva acumulada (verde) exhibe un crecimiento progresivo sin un codo pronunciado, lo que indica que la información está distribuida entre múltiples dimensiones moderadamente correlacionadas.

La varianza del componente 8 es de 0,040, mostrando que cada componente adicional aporta información marginal decreciente. Este comportamiento es propio de datasets con privaciones binarias donde cada indicador captura una dimensión relativamente independiente de la pobreza.

  • 8 componentes seleccionados → 54,1% de varianza acumulada
  • Componente 8: varianza individual = 0,040
  • Normalización de variables activada
  • N = 315.612 registros procesados

Scatter Plot — PC1 vs PC2

Proyección de los registros en el espacio de los dos primeros componentes principales, coloreados por grupo de pobreza.

Evidencia Orange · Scatter Plot PCA

Separación de grupos en el espacio PCA

La proyección en PC1 vs PC2 sobre una muestra de 5.000 registros revela una separación parcial pero consistente entre los grupos de pobreza. Los grupos A (Pobreza extrema, azul) y B (Pobreza moderada, rojo) se concentran en valores negativos de PC1, que captura las dimensiones de mayor privación estructural (educación y vivienda).

Box Plot — IPM Score por cluster

Distribución del índice de pobreza multidimensional por cada categoría, validando la separación estadística entre grupos.

Evidencia Orange · Box Plot

Distribución del IPM Score por grupo

El Box Plot del ipm_score segmentado por grupo_desc muestra diferencias estadísticamente significativas entre las cuatro categorías (ANOVA: F = 31.096,697, p = 0,000, N = 315.612).

El grupo D – No pobre presenta la menor dispersión (1,43 ± 1,4), mientras que A – Pobreza extrema alcanza el valor más alto (4,71 ± 2,4) con mayor variabilidad interna. Los grupos B y C actúan como categorías intermedias con distribuciones parcialmente superpuestas, lo que justifica la necesidad del clustering para capturar heterogeneidad dentro de cada categoría oficial.

  • D – No pobre: 1,43 ± 1,4 · menor dispersión
  • C – Vulnerable: 2,50 ± 1,7
  • B – Pobreza moderada: 3,74 ± 2,0
  • A – Pobreza extrema: 4,71 ± 2,4 · mayor variabilidad
  • ANOVA p = 0,000 → diferencias altamente significativas

Paso 10 · Evaluación de modelos

Test and Score — Comparación de clasificadores

Resultados de validación cruzada 10 folds estratificada para Árbol de Decisión, Random Forest y Naive Bayes.

Evidencia Orange · Modelos supervisados

Tres clasificadores entrenados en paralelo

El flujo de Orange conecta tres nodos de clasificación en paralelo al mismo nodo Test and Score: Random Forest, Tree (Árbol de Decisión) y Naive Bayes. Los tres modelos reciben el mismo conjunto de datos preprocesado y son evaluados simultáneamente bajo las mismas condiciones de validación cruzada.

Esta arquitectura permite comparar directamente el rendimiento de los tres enfoques sobre la variable objetivo es_pobre_ipm, garantizando que las diferencias en métricas sean atribuibles al algoritmo y no a variaciones en los datos de entrenamiento.

  • Random Forest → ensemble de árboles, mayor precisión
  • Tree → árbol simple, mayor interpretabilidad
  • Naive Bayes → clasificador probabilístico, menor costo computacional
  • Evaluación: validación cruzada 10 folds estratificada
Evidencia Orange · Test and Score

Resultados de los tres clasificadores

Los tres modelos fueron evaluados con validación cruzada de 10 folds estratificada sobre los 315.612 registros. El Random Forest alcanza un rendimiento excepcional con AUC = 1,000 y precisión del 99,9%, superando significativamente a los otros modelos.

El Árbol de Decisión logra AUC = 0,896 y CA = 0,859, siendo interpretable pero con mayor tasa de error. El Naive Bayes presenta AUC = 0,967 y CA = 0,892, con buen desempeño probabilístico pero limitado por la hipótesis de independencia entre variables que en este dataset no se cumple estrictamente.

  • Random Forest: AUC 1,000 · CA 0,999 · F1 0,999
  • Árbol de Decisión: AUC 0,896 · CA 0,859 · F1 0,860
  • Naive Bayes: AUC 0,967 · CA 0,892 · F1 0,892
  • p = 0,000 → Random Forest supera estadísticamente a los demás
Paso 11 · Interpretabilidad

Árbol de Decisión — Reglas de clasificación

Visualización del árbol con 11 nodos y 6 hojas que revela las variables más determinantes para predecir la pobreza IPM.

Evidencia Orange · Tree Viewer

Reglas interpretables del árbol

El árbol de decisión con 11 nodos y 6 hojas identifica bajo_logro_educativo como la variable raíz, siendo el discriminador más poderoso para clasificar la condición de pobreza IPM. Este resultado confirma lo observado en el clustering: la dimensión educativa es el principal eje de diferenciación entre grupos.

Las reglas principales revelan que personas con bajo logro educativo + sin acueducto tienen probabilidad del 95,5% de ser pobres por IPM (1.263/1.323 casos). En contraste, quienes no presentan bajo logro educativo ni empleo informal tienen probabilidad del 88,3% de no ser pobres (795/900 casos).

  • Raíz: bajo_logro_educativo (variable más discriminante)
  • bajo_logro=1 + sin_acueducto=1 → Pobre (95,5%)
  • bajo_logro=0 + empleo_informal=0 → No pobre (88,3%)
  • bajo_logro=1 + sin_acueducto=0 + Ama casa/Desempleado → Pobre (86,7%)
Paso 12 · Matrices de confusión

Matrices de confusión por modelo

Análisis detallado de los errores de clasificación para cada uno de los tres modelos sobre los 315.612 registros.

Árbol de Decisión

44.348 errores (14,1% de error total). El árbol presenta 28.781 falsos negativos — personas pobres clasificadas como no pobres — lo que implica riesgo de exclusión de beneficiarios reales. Los 15.567 falsos positivos representan clasificaciones incorrectas en sentido contrario. Este patrón asimétrico sugiere que el árbol tiene mayor dificultad identificando correctamente a la población pobre.

Random Forest

309 errores totales (0,1% de error). Random Forest comete apenas 25 falsos positivos y 284 falsos negativos sobre 315.612 registros. Esta precisión excepcional confirma que las privaciones del dataset definen de manera casi determinista la condición de pobreza IPM, y que el Random Forest captura estas relaciones con máxima eficiencia.

Naive Bayes

34.155 errores (10,8% de error). Naive Bayes presenta 17.352 falsos positivos y 16.803 falsos negativos, con una distribución más equilibrada entre tipos de error que el árbol. La hipótesis de independencia condicional introduce sesgo en variables altamente correlacionadas como bajo_logro_educativo y empleo_informal.

Análisis

Conclusiones del análisis K-Means

Resumen de los hallazgos clave y las implicaciones de la segmentación realizada.

El clustering K-Means muestra que el SISBEN IV se puede agrupar en cuatro segmentos de vulnerabilidad diferenciados. El cluster con mayor riesgo concentra las carencias más críticas en educación, salud y servicios básicos, mientras que el cluster de menor riesgo evidencia mayor acceso y menor privación.

  • Cluster de mayor vulnerabilidad: enfoque integral y prioritario en educación, vivienda y salud.
  • Cluster intermedio: atención focalizada en servicios básicos y empleo.
  • Cluster de menor carencia: acciones de prevención y fortalecimiento de capacidades.
  • Los resultados validan el uso de K-Means para identificar subgrupos relevantes más allá de los grupos A–D.
